# QR_Code_to_a4

Drag-and-drop tool that turns WiFi QR code images into printable A4 sheets.

Upload one or many WiFi QR code images and this tool will:

- Decode the QR code entirely in your browser (nothing is uploaded anywhere)
- Read the network name (SSID), password, and security type
- Generate a clean, print-ready A4 page with the original QR code centered and the WiFi details printed below it
- Let guests scan the code or read the credentials directly to join the network

No login, no backend, no build step. Open `index.html` or use the hosted version on GitHub Pages.
